# Product Overview

**jibun database** — 個人用 URL ブックマークデータベース。

URL を貼るだけで、サイト種別（YouTube / ニコニコ / X / 一般サイト）を自動判別し、タイトル・サムネイル等のメタデータを取得して保存する。閲覧は誰でも可能、登録・編集は本人のみ（メール+パスワード認証）。

## Core Capabilities

1. **URL 投入だけで登録完結** — URL ドメインから site_type を自動判別し、メタデータ（oEmbed / OGP）を自動取得
2. **サイト種別ごとの体験分岐** — X 投稿はメモ・カテゴリ不要で即登録、他はカテゴリ選択とメモ入力
3. **カテゴリ分類** — 固定 6 種（リリック / モーション / ボイロ / website / article / X）での整理
4. **お気に入り / アーカイブ** — 残したいものを star、見たくないものを archive。両者は排他
5. **公開閲覧 + 認証編集** — 読み取りは誰でも、書き込みは本人のみ（RLS で担保）

## Target Use Cases

- Twitter の「いいね」やブラウザブックマークでは流れてしまう情報を**集約して残す**
- 作業の参考資料（リリック / モーション / ボイロ 関連）を**カテゴリ別で引ける**状態にする
- 一度読んだ記事を**再訪できる自分だけの索引**にする

一人で使うことを前提にチューニングされている（多ユーザー想定なし）。

## Value Proposition

- **摩擦ゼロの登録**: URL を貼る以外の操作が最小。X 投稿はカテゴリ不要で 1 アクション登録
- **"流れない"場所**: SNS タイムラインやブラウザ履歴と違い、意図的に残す場所
- **個人最適**: 共有を想定していないため、カテゴリもメモも本人に分かれば良い粒度で運用できる
- **学習プロジェクト**: 個人学習を兼ねており、プロダクション級の堅牢性より「書いて学ぶ」を優先する方針
